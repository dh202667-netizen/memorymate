# 忆伴适老化界面改版

2026年11月17日，依据用户提供的《UI老年人设计》调整已有 uni-app 原型，保留双模式、38页和本地数据流程。

## 界面调整

| 文档要求 | 实际修改 |
| --- | --- |
| 温暖配色，减少蓝紫色 | 暖白背景 `#FFF9EF`，橙棕主按钮 `#8A481E`，暖黄与柔绿辅助色；旧数据的 blue 色调兼容为暖黄 |
| 黑体与至少16px正文 | 明确指定微软雅黑、苹方、黑体等非衬线字体；正文、说明、导航、输入提示均至少16px，保留三档字号 |
| 高对比度 | 正文 `#302D26`，辅助文字 `#665E51`；实际浏览器检查文字背景对比度至少4.5:1，修复 uni 输入框默认灰色提示字 |
| 明确的操作文案 | 去记录、开始动动脑、找忆伴聊聊、打开这个故事；去除主要页面的装饰性英文引导 |
| 大按钮与清楚边界 | 通用主按钮常规高度50px、18px文字、8px圆角；操作目标至少48px；放大字号时允许内容自然增高 |
| 至少8px间距 | 导航、选项、快捷按钮保留至少8px间隔；特大字号在窄屏下改为单列快捷入口 |
| 选择优先于输入 | 散步时长提供10/15/20/30分钟点选，也保留自定义时长 |
| 照片比插画更直接 | 家人头像、欢迎页与家庭故事采用本地写实AI示例照片，明确标识，用户上传图片保留原来源 |
| 颜色符合认知 | 成功提示为绿，错误提示为红，配合文字与图标，不依赖颜色单独表达 |
| 留足反应时间 | 操作提示由3.2秒延长到5.6秒，提供“关闭”；语音偏好控制本地成功提示音，不调整系统音量 |
| 移动时避免误触 | H5触摸移动超过10px后阻止本次拖动触发点击，下一次正常点击仍可使用；App保留平台滚动行为 |

长辈首页先展示常用操作和今日任务，再展示家庭故事与留言。家属端保留资料、活动事实和管理入口，使用相同的字体、颜色、表单与按钮。文档中的服药、如厕等事项仅作场景参考，本次未增加药物建议、医学评分或新的健康监测模块。

## 故事配图修正

- 春节全家福使用客厅家庭合影。
- 小红的第一次钢琴比赛使用女孩在钢琴舞台演奏的照片。
- 一家人的秋日旅行使用一家人在秋日公园出游的照片。
- 列表、故事详情、关联相册使用相同的图片来源。已有数据库只升级内置占位图，不替换上传文件、清除记录或重建家庭。
- 新故事未关联图片时显示明确的等待配图状态，避免自动套用全家福。

图片均为虚构家庭的AI示例，不是真实家人的照片。生成方式、提示词与素材位置见 [素材说明](08-示例图片说明.md)。

## 主要修改文件

- `mobile/src/styles/`：颜色、字体、间距和字号响应。
- `mobile/src/components/`：导航、按钮、标题、人物/故事/任务卡、表单、反馈、媒体、FamilyAvatar。
- `mobile/src/layouts/AppLayout.vue`：统一字体、特大字号布局、H5触摸误触防护。
- `mobile/src/pages/`、`mobile/src/modules/`：两种首页及各业务界面的统一改版。
- `mobile/src/mock/data.ts`、`mock/database.ts`：故事对应照片及新家庭的相册种子。
- `mobile/src/utils/presentation.ts`、`api/repositories.ts`：图片解析与旧占位图兼容。
- `mobile/src/stores/feedback.ts`、`utils/sound.ts`：可关闭的延长提示与本地成功音。
- `mobile/scripts/qa/ui-audit.cjs`、`ui-interactions.cjs`：界面检查与本次交互验收。

## 打开与运行

双击根目录 `启动忆伴.cmd`，预览地址为 `http://127.0.0.1:5173/`。保持启动窗口运行。Android连接授权后，在 `mobile` 执行 `scripts/run-android.ps1` 同步到官方调试基座；本轮仍未发行独立APK。
