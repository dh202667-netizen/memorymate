# 视觉与公共组件规范 v0.1

> v0.1历史基线：当前功能、工具版本与验收状态请查看 [v0.2实现与验收](06-v0.2-实现与验收.md)。


## 品牌方向

主题是「把熟悉的日常，留在身边」。奶油白承载内容，森林绿呈现主要动作，浅苔绿、雾蓝与杏色区分活动。少量原创植物和家庭插画增加亲切感，避免医疗仪表盘、病情预警红色和功能堆叠。

参考用户给出的温暖照护、家庭相册和认知活动方向。图片代理链接未能可靠读取，本轮设计依据文字要求与原创布局，不复制参考作品。

## 设计 token

| 语义 | 值 / 规则 |
| --- | --- |
| 页面背景 | `#F7F8F2` |
| 卡片 | `#FFFFFF` |
| 主品牌 | `#315B48`，白字主按钮 |
| 浅绿 | `#E9EFDF` |
| 辅助蓝 | `#E8EFF5` |
| 杏色 | `#F7ECD9` |
| 正文 / 次要文字 | `#263D33` / `#657269` |
| 边线 | `#E3E8DF` |
| 字号 | 默认正文 18px，说明 16px，标题 24–30px；大字 1.14 倍，特大 1.28 倍 |
| 底栏文字 | 默认 14px，完整可读标签，不依赖图标识别 |
| 操作区域 | 最小 48×48 CSS px，主按钮 54px 以上 |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32 |
| 圆角 | 小 12px、卡片 22px、主视觉 28px、胶囊 999px |
| 阴影 | 仅底栏与重要悬浮区域使用轻阴影 |

字号通过布局层变量统一传播，不能只放大某一页标题。按钮允许换行或增高，不将重要文字截断。图标采用本地 SVG 加可读标签；不引入外部字体、图标 CDN。

## 布局

- 移动端内容使用单列，页面边距 20px；Android 安全区加 `--status-bar-height`，底部使用 `env(safe-area-inset-bottom)`。
- H5 大屏以居中手机宽度呈现，正文不无限拉伸；保留适老化触控尺寸。
- 老人首页：品牌与模式 → 问候 → 今日记忆卡 → 任务 → 家人消息；每组一个主要动作。
- 家属首页：老人概览 → 活动事实 → 家属待办 → 家庭记忆快捷入口。数据注明为演示记录，不解释为认知水平。
- 一级页面统一品牌导航和底栏；二级页面明确标题与返回。
- 所有按钮有按下、禁用、键盘焦点状态；状态同时有文字；动画轻量，尊重减少动态效果。

## 公共组件契约

| 组件 | 责任 |
| --- | --- |
| `AppLayout` | 字号上下文、内容容器、安全区、标题、底栏、统一消息 |
| `PageHeader` | 品牌/标题、返回、切换身份入口 |
| `BottomNav` | 从 role + route 计算导航与选中状态 |
| `AppButton` | primary / secondary / ghost、禁用及点击事件 |
| `AppIcon` | 本地 SVG 图标，装饰图标不重复读屏 |
| `AppToast` | 统一可读状态与自动消退 |
| `SectionTitle` | 标题、辅助说明和可选行动 |
| `MemberCard` | 姓名、关系、头像、进入详情 |
| `StoryCard` | 封面插画、标题、日期、进入详情 |
| `TaskCard` | 明确任务动作、参与状态；当前只展示，不伪装成任务已完成 |
| `ModulePreview` | 未完成页说明、已规划区域与下一级入口 |

## 内容与状态

- 用“今天一起动动脑”“这次完成了 3 道题”，不用“降低患病概率”“治愈”“风险 80 分”。
- 温和错误：“暂时没有打开，请再试一次”；错误保留输入，加载按钮避免重复提交。
- Mock 的人物与活动始终标为演示；模拟语音和真实录音要区分。
- 没有记录时说明如何开始，不能凭空生成趋势。图表必须标注单位、时间范围和演示来源。
- 提醒、授权、删除等高影响动作应在对应业务阶段设计明确反馈；不使用假成功提示。

后续设备验收：360/390/412 宽度、特大字号、读屏标签、系统返回、软键盘遮挡、低网络、权限拒绝。当前浏览器截图不能替代 Android 原生可用性测试。
