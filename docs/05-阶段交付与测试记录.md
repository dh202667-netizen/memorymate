## 已修复的问题

- Vite 按 ESM 加载 DCloud 插件时 `uni is not a function`：改用官方模板的包加载方式，脚本保留 `.mjs`。
- Vue TS 把 `switch` 视为 SVG 元素：使用带明确状态的统一偏好按钮。
- H5 延迟注入的 uni-button 默认样式覆盖重置：提高重置选择器优先级，移除默认边线；无需强制点击。
- 预览 favicon 404：配置本地品牌 SVG。
- H5 键盘事件经 uni 归一化后 target 非 DOM：仅 H5 在组件根节点注册原生键盘事件，组件销毁时清理，Enter 选择角色已复测。
- App 导航参数避免依赖浏览器专有 `URLSearchParams`，使用标准 JS 编码。

格式化引发的 Vite 开发服务重启曾导致旧请求 504；重载后重新执行检查通过。未把开发期间的首次失败隐去或统计为通过。
