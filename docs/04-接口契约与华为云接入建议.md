# 接口契约与华为云接入建议

> v0.1历史基线：当前功能、工具版本与验收状态请查看 [v0.2实现与验收](06-v0.2-实现与验收.md)。


以下是未来实现建议；当前没有部署或开通任何云服务。

## 当前边界

页面 → `useFamilyStore` → `FamilyRepository` → Mock。`request.ts` 包含 HTTPS、超时、状态码与温和网络错误的基础封装；尚无 Token、重试、文件传输或流式实现。`VITE_DATA_SOURCE=http` 会明确返回“尚未接入”，不会伪装成线上数据。

`CompanionService.reply(messages)` 已定义，Mock 回复标记 `simulated: true`；当前聊天页面没有调用它。

## 建议后端结构

```text
uni-app → HTTPS / API 网关 → FastAPI
                             ├─ RDS PostgreSQL（结构化家庭、任务、记录、授权）
                             ├─ OBS（私有照片、声音、视频）
                             ├─ MaaS（经后端代理的大模型调用）
                             └─ Redis（规模需要时再加：限流、短期缓存、队列）
```

移动端不直接连接 RDS、不包含云 AK/SK 或 MaaS API Key。RDS 与 FastAPI 放在受控网络内，分开迁移账户和运行账户。OBS 使用私有对象，授权用户获取短期签名 URL；媒体上传先由后端验证家庭权限、文件类型、大小与授权状态。华为云支持通过临时授权 URL 完成指定对象上传，具体签名参数按接入时的 [OBS 文档](https://support.huaweicloud.com/intl/zh-cn/usermanual-obs/obs_03_1007.html) 实现。

MaaS 由 FastAPI 管理密钥、超时、配额和对话取消；对话先实现普通 JSON，再扩展可取消的流式传输。模型、区域和协议以接入时控制台及 [MaaS API 概览](https://support.huaweicloud.com/api-maas/api-maas-0002.html) 为准。模型回复不执行医学诊断，不将对话推测转为家属健康结论。只在明确授权范围内检索家庭故事，禁止跨家庭召回。

RDS PostgreSQL 的部署与连接步骤参见 [官方入门](https://support.huaweicloud.com/intl/en-us/qs-rds-pg/rds_02_0016.html)。本阶段无需采购云资源。

## 建议 API（待后端确认，不代表已实现）

| API | 用途 |
| --- | --- |
| `POST /v1/auth/session` | 真实身份认证 |
| `GET /v1/me` | 角色、家庭成员身份、授权范围 |
| `GET /v1/families/{family_id}/dashboard` | 双端聚合首页 |
| `GET/POST /v1/families/{family_id}/people` | 人物列表 / 新增 |
| `PATCH /v1/families/{family_id}/people/{person_id}` | 编辑人物 |
| `GET/POST /v1/families/{family_id}/stories` | 家庭故事 |
| `POST /v1/families/{family_id}/media/upload-ticket` | 私有媒体短期上传授权 |
| `POST /v1/families/{family_id}/media/complete` | 校验对象与元数据、完成登记 |
| `GET /v1/training/catalog` | 活动分类与题目版本 |
| `POST /v1/training/sessions` | 参与与答题事实 |
| `POST /v1/families/{family_id}/task-events` | 幂等任务完成事件 |
| `GET/POST /v1/families/{family_id}/observations` | 家属文字观察 |
| `POST /v1/conversations/{id}/messages` | 代理 MaaS，服务端检查授权 |
| `GET/POST/DELETE /v1/consents` | 授权查看、同意和撤回 |

约定：列表游标分页；时间以 ISO 8601 UTC 存储、客户端本地化；错误 `{code,message,request_id}`；创建请求带幂等键；编辑传版本号避免覆盖。以上写方法需要扩展当前 `request.ts` 的方法联合类型（当前仅预留 GET/POST/PUT/DELETE）。

## 推荐实体

`User`、`Family`、`FamilyMembership`、`Person`、`Relationship`、`Story`、`StoryPerson`、`MediaAsset`、`Consent`、`TaskEvent`、`TrainingSession`、`Observation`、`Message`、`ImportantDate`。家庭对象包含 `family_id`，服务端依据成员身份和授权过滤；本地 `mode` 只是界面偏好。

## 接入顺序

1. 冻结完整 Mock 行为与契约，再实现 HTTP adapter。
2. 真实登录、家庭邀请、授权和审计先于共享数据开放。
3. RDS 持久化人物、故事与实际活动；提供迁移、备份与删除策略。
4. OBS 私有媒体、上传取消、大小检查、授权过期续签。
5. MaaS 文字对话、内容边界与家人故事检索；之后才接 ASR/TTS。
6. 根据真实负载决定 Redis，补充监控、限流、恢复演练。
