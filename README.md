# 忆伴 MemoryMate · v0.3.0 Demo

## 在线体验

- **[立即打开忆伴网页版](https://dh202667-netizen.github.io/memorymate/)**。手机和电脑都可以直接体验。
- [下载 Android 安装包](https://github.com/dh202667-netizen/dh202667-netizen.github.io/releases/download/v0.3.0/MemoryMate-v0.3.0-android.apk)。适用于 ARM64 安卓设备。

进入网页版后，点击「开启温暖陪伴」，阅读演示说明，再选择长辈或家属身份。也可以点击「注册体验家庭」创建演示资料。

面向长辈与家属的认知健康活动、家庭记忆和日常陪伴原型。技术栈：**uni-app + Vue 3 Composition API + TypeScript**。

当前已经实现完整的双模式本地体验流程。38 个页面均有实际内容；不再使用通用占位页面。所有业务使用同一个 Mock 仓库和设备本地存储，不连接真实认证、数据库或大模型。

2026年11月17日已完成适老化UI更新：至少16px文字、暖色与高对比度、可关闭的延长提示、点选散步时长，以及分别对应春节、钢琴比赛和秋游的三张示例照片。旧占位图自动兼容，用户上传图片保留。改版内容与实际验收见 [UI改版记录](docs/07-适老化UI改版.md)，图片来源与提示词见 [素材说明](docs/08-示例图片说明.md)。

## 推荐体验顺序

1. 长辈模式 → 记忆家园 → 老伴/儿子/孙女 → 故事 → 照片大图或语音。
2. 动动脑 → 任意类型 → 完成3题 → 结果 → 历史。
3. AI陪伴 → 选择话题或输入文字；点两次语音演示按钮可填入一句模拟识别文本。
4. 首页 → 今日目标 → 记录散步；完成训练后返回查看任务变化。
5. 切换家属 → 记忆管理 → 添加人物与故事 → 关联照片 → 切回长辈查看同一份资料。
6. 家庭互动 → 留言/分享照片 → 切回长辈消息页读取；健康观察新增一条日常备注。
7. 长辈隐私设置中暂停活动分享或家属编辑，再切换家属验证界面变化。

## 架构与目录

```text
elderly/
├── docs/                     # 页面图、规范、分阶段及实际验收记录
└── mobile/
    ├── scripts/              # 路由检查、Android运行、CLI场景验收
    ├── src/
    │   ├── pages/            # 38个页面入口，按角色和模块组织
    │   ├── modules/          # memory / training / companion / health / family / account
    │   ├── components/       # 导航、标题、按钮、表单、开关、空态、媒体与内容卡片
    │   ├── layouts/          # 安全区、字号、导航和角色入口检查
    │   ├── composables/      # 页面参数与统一数据加载
    │   ├── api/              # 本地repository、模拟陪伴service；通用请求封装预留
    │   ├── mock/             # 全部种子资料、题库、回复规则与媒体目录
    │   ├── stores/           # 会话、偏好、家庭事务、统一反馈
    │   ├── types/
    │   ├── utils/            # 路由、日期、媒体持久化、确认与错误处理
    │   ├── static/           # 原创插画、PNG预览素材、本地合成示例语音
    │   ├── styles/
    │   ├── App.vue
    │   ├── pages.json
    │   └── manifest.json
    ├── package.json
    └── package-lock.json
```

页面 → store → repository → Mock/本地存储。种子资料、题目和回复规则集中在 `mock/`；页面不导入 Mock。写操作先在副本中校验，再持久化，成功后更新界面，存储失败不显示假成功。删除人物会清理故事/媒体关联；删除故事保留媒体，移除其故事关系。

页面目录图见 [页面架构](docs/02-产品架构与页面清单.md)；其状态列记录的是v0.1规划，当前实现以本说明与v0.2验收记录为准。

## 本地数据与边界

- 长辈/家属模式共用同一设备数据，不能跨手机同步。邀请与授权为本地交互模拟，不是真实账户认证。
- 数据使用 `memorymate.v1.database.v2` 命名空间；阅读偏好单独保存。退出仅清除模式，不删除家庭记录。
- 浏览器媒体转为本地数据保存，单附件限制1.5MB；App使用 `uni.saveFile` 保存选择的文件副本。原始相册文件不会被删除。
- “恢复初始示例家庭”需要确认，会清除本地新增记录；App还会清理通过保存接口保留的文件副本。
- 示例记录明确标注；训练历史从空开始，由实际作答产生。“—”表示没有记录，不代表没有活动。
- 语音输入为模拟；示例语音是本地合成音。没有真实录音、ASR或逐条回复的实时TTS。真实个人语音文件导入尚未提供，当前可添加和播放示例语音。
- 通知仅控制应用内提示，未实现系统推送/后台定时提醒。
- 保留数据访问契约，后端选型与接口在后续确认；本轮未增加后端服务或外部调用。早期云端方案见历史规划文档，不是当前已启用配置。

## 验证与继续开发

[云端构建检查](https://github.com/dh202667-netizen/memorymate/actions/workflows/build.yml)包括类型、路由和构建验证，并提供可下载的网页构建产物。场景验收脚本位于 `mobile/scripts/qa/`，详细结果、设备范围与未覆盖项见[开发交接说明](docs/10-开发交接说明.md)。

新增页面先编写业务页面，再登记 `src/config/routes.json`，运行 `npm run pages:generate`。生成器同步路由并检查实体，不会批量制造空页。公共视觉维护在 `styles/` 和 `components/`。

当前未实现：真实账户、跨设备家庭服务、数据库/云存储/大模型、真实语音识别、系统通知和正式发行。后续先补跨设备的数据与授权契约，再确定后端技术与云服务，保持页面与数据适配器分离。
